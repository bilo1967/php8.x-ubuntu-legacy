# PHP 8.4.28 for Ubuntu 20.04 LTS (Focal)

Unofficial **amd64** packages built from the Sury Debian source package `php8.4_8.4.28-2+debsuryorg22.04.1+php+1.dsc`, retaining the original core packaging with a local version suffix.

This release contains PHP core packages only. Use the existing [PHP 8.4 PECL release](https://github.com/bilo1967/php8.x-ubuntu-legacy/releases/tag/v8.4.27-pecl-focal.1) with this core. Those extensions were built against PHP 8.4.27, share PHP API `20240924`, and do not require rebuilding for this patch update. Their tag records the original build baseline.

## Security update: 8.4.28

PHP 8.4.28 is an upstream security release dated 19 November 2026. These packages rebuild the Sury source package for Focal; the security fixes come from that PHP/Sury source, rather than separately maintained local backports.

## Installation and validation

Download only the required Debian packages and install them together using `apt`. Verify `SHA256SUMS` in the download directory first. Asset filenames omit `~` because GitHub normalizes it; the Debian package contents and internal versions are unchanged.

The maintainer reports Moodle and Nextcloud running on Ubuntu 20.04 with PHP 8.4.28 and the existing PECL packages. For PHP 8.4, these runtime checks used the earlier build that failed only when downloading shared `php-common`; the release uses the subsequent successful core run. This is an application smoke check, not a full automated PHP test suite.

The shared Sury `php-common` package is included and may update system-wide PHP management scripts. Its SHA-256 is pinned independently.

The release includes `source-files.sha256` and `BUILD-ORIGIN.txt` for source checksums and build provenance. Core and PECL remain separate. A PHP update does not update Ubuntu system libraries.
